# Support

- Usage and architecture questions: open a GitHub issue with the `question`
  label.
- Bug reports: use the bug report template and include the toolkit version,
  Python version, host OS, command, and a sanitized error excerpt.
- Feature requests: use the feature request template and explain the evidence
  path and expected output.
- Security issues: follow [SECURITY.md](SECURITY.md).

Do not upload target APKs, recovered third-party DEX/native code, embedded
payloads, device serials, personal paths, or credentials. A minimal synthetic
reproduction is preferred.

The project is maintained on a best-effort basis; no response-time guarantee is
made.
